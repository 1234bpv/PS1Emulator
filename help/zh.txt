# PS1Emulator帮助文本，简体中文。UTF-8。
# 章节以行首的 [key] 开始。
#   [hint.<id>] 选定菜单项在状态栏显示的单行提示。
#   [topic.<id>] 标题及正文：每行一个段落，空行为间隔。
# 数值为诺基亚 N95 8GB 上的实测数据，仅供参考：实际表现取决于游戏。

[hint.start] 使用以下设置启动选中的游戏。会首先检查光盘镜像和BIOS。
[hint.resume] 返回游戏并从离开时的状态继续。
[hint.restart] 标有 * 的项已更改：游戏将重新开始且未保存进度会丢失。请先保存状态。
[hint.exit] 保存设置并关闭模拟器。若未保存状态，正在运行的游戏进度将丢失。

[hint.sec.game] 按OK展开或折叠该分组：游戏、保存状态与导入游戏。
[hint.game] 要游玩的光盘镜像。按OK打开文件浏览器。更改此项需重启游戏。
[hint.savestate] 将运行中的游戏保存到所示槽位（左/右：1-5）。槽位后带 [*] 表示已有存档将被覆盖，[ ] 表示为空。
[hint.loadstate] 读取所示槽位。该保存点之后的进度将会丢失。
[hint.add] 从存储卡导入游戏：镜像以及 zip、rar 或 7z 压缩包，可选择打包为 PBP。

[hint.sec.video] 按OK展开或折叠该分组：缩放、边缘平滑、显示帧率与画面开关。
[hint.smooth] 在640宽度的画面缩小缩放时对像素求平均。实测关闭可节省4.6%的运行时间。
[hint.fxaa] 平滑3D物体的锯齿边缘；数值越高效果越强。实测在测试场景中会降低约17%的帧率。
[hint.fps] 在画面上显示帧率。有助于评估其他开关设置对性能的影响。
[hint.light] 3D光照。关闭速度更快但会失去明暗阴影：实测在 Gran Turismo 场景中减少5.6%的CPU周期。
[hint.blend] 半透明效果（玻璃、发光、阴影）。关闭速度更快，但此类物体显示会不正常。
[hint.dirty] 不重绘游戏画面未变的部分。实测：每帧节省 6.7 ms，且不损失画质。
[hint.dsa] 直接将帧写入屏幕缓冲区。实测：每帧节省 0.93 ms。需重启游戏。
[hint.gl] 通过手机的 OpenGL ES 输出画面。在实测的一个 320x240 场景中比不开启更慢。需重启。
[hint.swdraw] 仅在GL输出开启时有效。开：软件光栅化器绘制，GL仅负责显示帧。关：由图形芯片绘制。
[hint.ilace] 仅隔行绘制。速度更快，但垂直分辨率细节减半。
[hint.pixskip] 在高水平分辨率模式下跳过不可见的像素。速度略快一些。

[hint.sec.speed] 按OK展开或折叠该分组：跳帧与处理器设置。其中多数需重启生效。
[hint.gpuskip] 跳过部分帧不进行绘制。自动由核心自行决定。在赛车场景实测中设为1提升了27%的模拟速率，但显示帧数减少了37%。
[hint.cpu] 动态重编译将 PS1 代码重编译为 ARM，是快速模式。解释器是较慢的模式。需重启。
[hint.gtenf] 跳过几何协处理器的部分标志位计算。在 Gran Turismo 中速度反而慢了6%，因为几何结构发生了变化。需重启。
[hint.cycle] 模拟的 PS1 处理器速度百分比。调低会减轻手机负担但可能影响游戏时序。立即生效。

[hint.sec.sound] 按OK展开或折叠该分组：声音输出与音调。
[hint.sound] 声音输出。关闭将静音并节省音频通道占用的处理器时间。需重启游戏。
[hint.wsola] 当游戏运行低于全速时，在不改变音调的情况下拉伸声音。实测在 N95 上约消耗6%的每帧时间。需重启。

[hint.sec.input] 按OK展开或折叠该分组：按键预设、按键映射与重力感应控制。
[hint.preset] 使用预设布局替换所有按键映射。左/右选择，OK应用。您自定义的映射将会丢失。
[hint.keybase] 基础布局：N95 为默认；C5 还支持将 2、4、6、8 作为方向的第二按键。OK应用并替换当前映射。
[hint.keys] 打开按键映射页面：按OK后按下按键。左/右可为按键开启或关闭连发。
[hint.tilt] 通过手机倾斜（加速度计）进行转向。返回游戏时手持手机的姿势即为中立位置。
[hint.tiltside] 对应左右倾斜的摇杆轴（LX、LY、RX、RY；负号表示反转）。默认为 LX。
[hint.tiltpitch] 对应前后倾斜的摇杆轴（LX、LY、RX、RY；负号表示反转）。默认为 LY。
[hint.tiltdead] 小于此数值的倾斜将被忽略。范围 0 到 40，默认 10。
[hint.tiltsens] 摇杆随倾斜移动的灵敏度：40% 到 300%，默认 100%。

[hint.sec.system] 按OK展开或折叠该分组：语言、BIOS、独立游戏配置与恢复默认设置。
[hint.lang] 菜单语言。立即生效。帮助文本也会随之改变；缺失文本将回退为英文。
[hint.bios] 来自 E:\PS1\bios 的 BIOS 镜像。若没有，将运行内置替代程序(HLE)，兼容性较差。需重启。
[hint.profile] 开：每个游戏在 E:\PS1\cfg 中保留各自的设置，例如按键和速度开关。关：所有游戏共用一套设置。
[hint.reset] 将所有设置恢复为默认值，包括按键与语言。按两次OK确认。存档不受影响。

[hint.help] 打开帮助：初始设置、按键操作、存档、故障排除以及每个菜单项的说明。

[topic.setup] 初始设置
本项将打开初始设置页面，即模拟器在首次启动时显示的页面。

[topic.play] 游戏中操作
菜单按键：上和下移动，左和右修改数值，OK打开或切换选项，C和右软键返回。

主菜单导航：上和下在首尾行之间循环切换。在分组标题上按右展开、按左折叠；展开一个分组会自动折叠另一个。在分组内按C会折叠该分组并将光标留在其标题上。在数值项上按OK的效果与按右相同。

游戏中右软键可打开菜单并暂停游戏。左软键用于截图。来电或切换到其他应用程序时，游戏会自动暂停并打开菜单。

默认按键：方向键移动；OK或5为叉；0为圆；7为方；9为三角；1为L1；3为R1；4为L2；6为R2；2为Select；8为Start。

两种基础布局均使用方向键控制方向。按键中的键盘项可选择基础布局：N95 为默认；C5 还支持数字键盘上的 2、4、6 和 8 作为四个方向的第二按键，方便习惯数字键的用户。

使用侧边音量键调节音量，或使用 #（增大）和 *（减小），除非这些按键已被映射到手柄按钮。

每个按钮均可在按键映射...中进行分配：在按钮上按OK，然后按下按键。左和右可开启连发：开启连发的按钮将保持按下状态直至再次按下，适合赛车游戏中的油门。

重力感应控制（按键）可通过手机倾斜进行转向。需要配备加速度计的手机，例如 N95；E90 和 C5-00.2 则没有配备。

每次从菜单返回游戏时都会获取中立位置。如需重新校准，用右软键打开菜单，以您习惯游玩的姿势拿稳手机，然后选择继续。

[topic.saves] 存档
即时存档可保存游戏某一时刻的全部状态。打开游戏，选择保存状态，用左和右选择槽位（1 到 5）并按OK。槽位编号后的 [*] 表示该槽位已有存档，[ ] 表示为空。读取状态可恢复该状态。

保存状态和读取状态仅在游戏运行中且为当前选中游戏时才会显示。

状态文件保存在 E:\PS1\saves 中，以游戏和槽位命名。游戏的记忆卡 card1.mcd 和 card2.mcd 也在同一文件夹中：用于保存游戏自身写入的存档。即时状态与记忆卡存档彼此独立。

标有 * 的项需重启游戏生效。未保存的进度将会丢失，因此在更改这些项之前请先保存状态。

[topic.slow] 如果游戏运行缓慢
逐项进行调整并观察显示帧率（画面）。

首先是不影响画质的设置。直接绘制和跳过重复帧应保持开启：它们不会损失画质。实测关闭平滑缩放可节省 4.6% 的运行时间，并且它仅用于柔化细线。

接下来是跳帧。自动最为平滑。在赛车场景实测中固定设为 1 可提高 27% 的模拟速度，但显示的帧数减少了 37%。

然后是以牺牲画质为代价的设置：关闭边缘平滑、关闭3D光照（实测场景中减少 5.6% 的 CPU 周期）、关闭半透明效果、隔行扫描优化、像素跳线。调低 PS1 CPU主频 可减轻负担但可能扰乱游戏时序。

以下项通常没有帮助：GTE加速模式在 Gran Turismo 中反而慢了 6%；在实测 320x240 场景中 GL输出比软件路径更慢。CPU核心保持为动态重编译：解释器是较慢的模式。

[topic.nosound] 没有声音或没有画面
没有声音：检查声音（位于声音分组）是否开启，以及更改后是否重启了游戏。使用侧键、# 或 * 调高音量。如果保持音调处于开启状态，请尝试将其关闭。

没有画面或黑屏：按右软键并查看错误页面。未找到光盘镜像或BIOS意味着文件缺失：请参阅存储卡上的文件。如果更改后画面异常，请关闭直接绘制或GL输出并重启游戏。

无 BIOS：游戏将使用内置替代程序(HLE)运行。许多游戏可以启动，但兼容性较差。请将 BIOS 镜像放入 E:\PS1\bios 或在系统、BIOS中选择一个。

光盘镜像支持的格式包括 bin、img、iso、pbp、cbn 和 cbin。cue 文件不会列在游戏浏览器中：核心会根据名称自动关联 bin 对应的 cue，因此请将它们放在一起。导入功能会列出 cue 文件。

[topic.files] 存储卡上的文件
E:\PS1\games 存放光盘镜像。添加游戏...可让您从存储卡任意位置导入镜像。

E:\PS1\bios 存放 BIOS 镜像。默认文件名为 scph7502.bin。可在系统、BIOS中选择镜像文件或包含该文件的 zip、rar、7z 压缩包。

E:\PS1\saves 存放即时存档与记忆卡文件。

E:\PS1\cfg 存放全局设置文件 ps1_settings.txt，以及为每个拥有独立设置的游戏存放的小配置文件。

E:\PS1\help 存放这些帮助文本：每种语言一个文件，按语言代码命名（en.txt、uk.txt），采用 UTF-8 编码。若缺少文件或缺少键则回退为英文。

E:\PS1\logs 存放运行日志。

[topic.game] 游戏
游戏：要游玩的光盘镜像。按OK打开当前游戏所在文件夹的文件浏览器。游戏运行期间选择其他光盘需要重启。

保存状态与读取状态：请参阅存档章节。

添加游戏...：从存储卡导入游戏。用OK标记文件或压缩包，用左软键开始导入。您可以将它们打包为 PBP，可节省约40%空间，但这会移除纠错数据且无法撤销，您还可以选择删除原文件。导入正在运行的游戏光盘将关闭该游戏。

[topic.video] 画面
平滑缩放：在 640 宽度的画面缩小缩放时对像素求平均。

边缘平滑：平滑 3D 物体的锯齿边缘，级别 1 到 5。

显示帧率：在画面上方显示帧率。

该分组其余项：3D光照（纹理明暗）、半透明效果（半透明物体）、跳过重复帧（不重绘未变化的画面）、直接绘制（直接写入屏幕缓冲区，需重启）、GL输出（通过 OpenGL ES 显示画面，需重启）、软件绘制（仅限GL：选择哪个光栅化器进行绘制）、隔行扫描优化（仅隔行绘制）以及像素跳线（在高水平分辨率模式下跳过不可见的像素）。

[topic.speed] 速度
跳帧：跳过部分帧不进行绘制。自动由核心逐帧决定；1 到 3 表示在绘制的帧之间跳过相应数量的帧。

该分组其余项：CPU核心（动态重编译或解释器，需重启）、GTE加速模式（需重启）和 PS1 CPU主频。

PS1 CPU主频以正常速度的百分比显示。较低的值使游戏每帧处理较少工作量，但可能破坏游戏时序。立即生效。

[topic.sound] 声音
声音：开启或关闭声音输出，需重启。

保持音调：当游戏运行低于全速时，拉伸声音而不改变音调。会消耗处理器时间并需重启。

[topic.input] 按键
按键预设：默认、赛车、格斗或 RPG。按OK替换所有按键映射。

键盘：N95（默认布局）或 C5（相同布局，外加 2、4、6、8 作为方向的第二按键）。按OK替换所有按键映射。

按键映射...：将每个 PS1 按钮分配到按键；左和右开启或关闭连发。

重力感应控制及其四项设置：左右倾斜轴、前后倾斜轴、死区（0 到 40）和灵敏度（40% 到 300%）。

[topic.system] 系统
语言：菜单和这些文本的语言，立即生效。

BIOS：使用的 BIOS 镜像，需重启。默认为 scph7502.bin。

独立游戏配置：开启时为每个游戏保留单独的设置文件。

恢复默认设置：将所有设置恢复为默认值；按两次OK。
