[topic.setup] 초기 설정
이 항목은 에뮬레이터를 처음 실행할 때 표시되는 초기 설정 페이지를 엽니다.

[topic.play] 게임 내 조작
메뉴 키: 위와 아래는 이동, 왼쪽과 오른쪽은 값 변경, OK는 항목을 열거나 전환, C와 오른쪽 소프트키는 뒤로 이동합니다.

메인 메뉴 탐색: 위와 아래는 마지막 항목과 첫 항목 사이를 순환합니다. 섹션 헤더에서 오른쪽을 누르면 열리고 왼쪽을 누르면 닫히며, 한 섹션을 열면 다른 섹션은 닫힙니다. 섹션 내부에서 C를 누르면 섹션이 닫히고 커서가 해당 헤더에 남습니다. 값 항목에서 OK를 누르면 오른쪽을 누른 것과 똑같이 변경됩니다.

게임 중 오른쪽 소프트키를 누르면 메뉴가 열리고 게임이 일시 정지됩니다. 왼쪽 소프트키는 스크린샷을 찍습니다. 전화가 오거나 다른 애플리케이션으로 전환하면 게임이 일시 정지되고 메뉴가 자동으로 열립니다.

기본 키: 방향키는 이동, OK 또는 5는 엑스, 0은 동그라미, 7은 네모, 9는 세모, 1은 L1, 3은 R1, 4는 L2, 6은 R2, 2는 Select, 8은 Start입니다.

두 배열 모두 방향키로 조작합니다. 조작의 키보드 항목에서 기본 배열을 선택할 수 있습니다. N95가 기본값이며, C5는 숫자 키패드가 더 편한 사용자를 위해 숫자 키패드의 2, 4, 6, 8도 네 방향의 보조 키로 지원합니다.

볼륨은 측면 볼륨 키로 조절하거나 해당 키가 버튼에 할당되지 않은 경우 #(크게) 및 *(작게)로 조절할 수 있습니다.

모든 버튼은 조작 설정... 에서 할당할 수 있습니다: 버튼에서 OK를 누른 다음 키를 누르세요. 왼쪽과 오른쪽은 연사를 켭니다: 연사 버튼은 다시 누를 때까지 누른 상태를 유지하므로 레이싱 게임의 가속에 적합합니다.

기울기 조작(조작)은 폰의 기울기로 조작합니다. N95처럼 가속도계가 있는 폰이 필요하며, E90과 C5-00.2에는 가속도계가 없습니다.

메뉴에서 게임으로 돌아올 때마다, 그리고 기울기 영점 키를 누를 때마다 중립 위치가 다시 잡힙니다. 이 키는 기본적으로 C이며 조작 설정... 의 마지막 행에서 다시 지정할 수 있습니다. 재보정하려면 게임을 플레이할 자세로 폰을 쥐고 해당 키를 누르세요.

[topic.saves] 저장
상태 저장은 게임의 전체 상태를 한순간에 저장합니다. 게임을 열고 상태 저장을 선택한 뒤 좌우로 슬롯(1~5)을 고르고 OK를 누르세요. 슬롯 번호 뒤의 [*]는 이미 상태가 저장되어 있음을 의미하며 [ ]는 비어 있음을 의미합니다. 상태 불러오기로 복원할 수 있습니다.

상태 저장 및 상태 불러오기는 게임이 실행 중이고 해당 게임이 선택되어 있을 때만 나타납니다.

상태 저장 파일은 E:\PS1\saves 에 게임 이름과 슬롯 이름으로 저장됩니다. 게임의 메모리 카드인 card1.mcd 및 card2.mcd도 같은 폴더에 있으며, 게임 자체가 기록하는 저장 데이터가 담깁니다. 상태 저장과 메모리 카드는 서로 독립적입니다.

* 표시가 된 항목은 게임 재시작이 필요합니다. 저장하지 않은 진행 상황은 손실되므로 변경하기 전에 상태를 저장하세요.

[topic.slow] 게임 속도가 느릴 때
한 번에 하나씩 설정을 변경하면서 FPS 표시(비디오)를 확인하세요.

먼저 부담이 적은 항목부터 확인합니다. 직접 그리기와 동일 프레임 건너뛰기는 켬 상태를 유지해야 합니다: 화질 저하가 없습니다. 부드러운 확대 끔은 가는 선만 약간 부드럽게 하지 않을 뿐 측정된 트레이스에서 실행 시간을 4.6% 절약했습니다.

그다음은 프레임 스킵입니다. 자동이 가장 자연스럽습니다. 측정된 레이싱에서 고정값 1은 에뮬레이션 속도를 27% 향상시켰지만 표시되는 프레임은 37% 감소했습니다.

그다음은 화면 품질을 희생하는 설정입니다: 가장자리 부드럽게 끔, 3D 조명 끔(측정된 장면에서 CPU 사이클 5.6% 감소), 반투명 효과 끔, 인터레이스 최적화, 픽셀 스킵. PS1 CPU 클록을 낮추면 부담은 줄어들지만 게임의 타이밍이 깨질 수 있습니다.

다음에 대해서는 큰 기대를 하지 않는 것이 좋습니다: GTE 고속 모드는 Gran Turismo에서 6% 더 느렸으며, GL 출력은 측정된 320x240 장면에서 소프트웨어 경로보다 느렸습니다. CPU는 다이렉 재컴파일로 유지하세요: 인터프리터는 느린 모드입니다.

[topic.nosound] 소리나 화면이 나오지 않을 때
소리가 안 남: 사운드(사운드 섹션)가 켬인지 확인하고 변경 후 게임을 재시작했는지 확인하세요. 측면 키나 #, *로 볼륨을 높이세요. 음정 유지가 켜져 있다면 꺼보세요.

화면이 안 나오거나 검은 화면: 오른쪽 소프트키를 누르고 오류 페이지를 확인하세요. 디스크 이미지 또는 BIOS를 찾을 수 없음 오류는 파일이 없음을 뜻합니다: 카드 내 파일 항목을 참고하세요. 설정 변경 후 화면이 이상하면 직접 그리기나 GL 출력을 끄고 게임을 재시작하세요.

BIOS 없음: 게임이 내장 대체재(HLE)로 구동됩니다. 많은 게임이 시작은 되지만 호환성이 떨어집니다. E:\PS1\bios 에 BIOS 덤프를 넣거나 시스템의 BIOS에서 선택하세요.

디스크 이미지는 bin, img, iso, pbp, cbn, cbin 형식으로 표시됩니다. cue 파일은 게임 탐색기에 나타나지 않습니다: 코어가 파일 이름을 통해 bin으로부터 유추하므로 둘을 함께 보관하세요. 게임 추가에서는 cue 파일도 표시됩니다.

[topic.files] 카드 내 파일
E:\PS1\games 폴더에는 디스크 이미지가 저장됩니다. 게임 추가... 를 사용하면 카드의 어느 위치에서든 가져올 수 있습니다.

E:\PS1\bios 폴더에는 BIOS 덤프가 저장됩니다. 기본 이름은 scph7502.bin입니다. 시스템의 BIOS에서 덤프 또는 이를 포함한 zip, rar, 7z 압축 파일을 선택할 수 있습니다.

E:\PS1\saves 폴더에는 상태 저장 파일과 메모리 카드가 보관됩니다.

E:\PS1\cfg 폴더에는 전역 설정 파일인 ps1_settings.txt와 개별 설정이 있는 게임별 작은 설정 파일이 저장됩니다.

E:\PS1\help 폴더에는 이 도움말 텍스트가 저장됩니다: UTF-8 형식으로 언어 코드 이름을 딴 언어별 파일 하나씩(en.txt, uk.txt 등) 보관됩니다. 파일이나 키가 없으면 영어로 대체됩니다.

E:\PS1\logs 폴더에는 실행 로그가 저장됩니다.

[topic.game] 게임
게임: 플레이할 디스크 이미지입니다. OK를 누르면 현재 게임이 위치한 폴더의 파일 탐색기가 열립니다. 게임 실행 중에 다른 디스크를 선택하면 재시작해야 합니다.

상태 저장 및 상태 불러오기: 저장 항목을 참고하세요.

게임 추가...: 카드에서 게임을 가져옵니다. OK로 파일이나 압축 파일을 선택하고 왼쪽 소프트키로 시작하세요. PBP로 압축할 수 있으며 약 40% 절약되지만 오류 정정 데이터가 제거되어 되돌릴 수 없습니다. 원본 삭제도 가능합니다. 실행 중인 게임의 디스크를 가져오면 해당 게임이 종료됩니다.

[topic.video] 비디오
부드러운 확대: 640 너비의 화면을 축소할 때 픽셀 평균을 냅니다.

가장자리 부드럽게: 3D 형상의 계단 현상을 부드럽게 다듬습니다. 레벨 1부터 5까지 지원합니다.

FPS 표시: 화면 위에 프레임 레이트를 표시합니다.

섹션의 나머지 항목: 3D 조명(텍스처 음영), 반투명 효과(반투명 물체), 동일 프레임 건너뛰기(변경되지 않은 화면 다시 그리지 않음), 직접 그리기(화면 버퍼에 바로 기록, 재시작 필요), GL 출력(OpenGL ES를 통해 화면 표시, 재시작 필요), 소프트웨어 렌더링(GL 시에만: 어느 래스터라이저가 그릴지), 인터레이스 최적화(한 줄씩만 그림), 픽셀 스킵(높은 수평 해상도 모드에서 보이지 않는 픽셀 생략).

[topic.speed] 속도
프레임 스킵: 일부 프레임을 그리지 않습니다. 자동은 코어가 매 프레임마다 결정하며, 1에서 3은 그려지는 프레임 사이에 그 수만큼의 프레임을 건너뜁니다.

섹션의 나머지 항목: CPU(다이렉 재컴파일 또는 인터프리터, 재시작 필요), GTE 고속 모드(재시작 필요), PS1 CPU 클록.

PS1 CPU 클록은 정상 속도 대비 백분율(%)로 표시됩니다. 값을 낮추면 프레임당 게임 처리 작업량이 줄어들지만 게임 타이밍이 깨질 수 있습니다. 즉시 적용됩니다.

[topic.sound] 사운드
사운드: 사운드 출력 켬 또는 끔, 재시작 필요.

음정 유지: 게임이 정상 속도보다 느리게 실행될 때 음정 변화 없이 소리를 늘립니다. 프로세서 시간이 소모되며 재시작이 필요합니다.

[topic.input] 조작
조작 프리셋: 기본값, 레이싱, 격투, RPG. OK를 누르면 모든 키 할당이 교체됩니다.

키보드: N95(기본 배열) 또는 C5(동일 배열에 네 방향의 보조 키로 2, 4, 6, 8 추가). OK를 누르면 모든 키 할당이 교체됩니다.

조작 설정...: 각 PS1 버튼에 키를 할당합니다. 왼쪽과 오른쪽은 연사를 켜거나 끕니다. 마지막 행인 기울기 영점은 폰의 현재 위치를 중립으로 만드는 키입니다.

기울기 조작 및 네 가지 설정: 좌우 기울기 축, 앞뒤 기울기 축, 데드존(0~40), 감도(40%~300%).

[topic.system] 시스템
언어: 메뉴 및 이 텍스트의 언어이며, 즉시 변경됩니다.

BIOS: 사용할 BIOS 덤프이며, 재시작이 필요합니다. 기본값은 scph7502.bin입니다.

게임별 설정: 켬으로 설정하면 각 게임마다 별도의 설정 파일을 유지합니다.

디버그 로그: 켬으로 설정하면 초당 1회 프레임 시간과 모든 화면 정지를 E:\PS1\logs\ps1_stage1.jsonl 에 기록합니다. 문제를 보고하려면 이를 켜고 문제가 발생할 때까지 플레이한 뒤, 종료를 통해 에뮬레이터를 나가 해당 파일을 보내세요. 직전 실행 로그는 ps1_stage1_prev.jsonl 로 보관됩니다.

설정 초기화: 모든 설정을 기본값으로 되돌립니다. OK를 두 번 누르세요.
