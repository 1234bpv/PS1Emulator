# Заміри та валідація Gouraud ARM (+&r) і відхиленого 8bpp спану

**Дата:** 2026-09-28  
**Апарати:** Nokia N95 8GB (OMAP 2420, 330.24 МГц), Nokia E90 (OMAP 2420, 330.24 МГц), Nokia C5-00.2 (ARM11, COM5 SPP).  
**Прийнятий коміт ядра:** [`cb47fc6cc5acabab56f4c88ebeb10167439170c8`](file:///H:/VsCodeProjects/SymbianProjects/PS1Emulator/pcsx_rearmed) (`perf(gpu): avoid stack spill in gpuLightingTXTGouraudARM`).  
**Релізний бінарник:** `ps1stage1.exe` (1 345 764 байти, SHA256: `39e20e8e380742787c0e03cd215e1cc981483c6d57492c436837f86d22b860ad`).

## 1. Підсумок оптимізаційного дослідження

Досліджено два незалежні шляхи оптимізації растеризатора `gpu_unai`:
1. **Прийнято (+&r):** Констрейнт `+&r` в інлайн-асемблері `gpuLightingTXTGouraudARM` (`plugins/gpu_unai/gpu_inner_light_arm.h`). Усуває скидання регістрів на стек (stack spill) на кожен піксель, заощаджуючи 1 інструкцію та 2 звернення до пам'яті на непрозорий тексель.
2. **Відхилено (CF0c1 8bpp Span ASM):** Асемблерний спан `poly_8bp_lgd0m0std_asm` (`CF=0x0c1`). Повністю коректний, але на фізичному N95 показав медіанне уповільнення +0.22% (30 255 ms vs 30 190 ms). За правилом нульового виграшу кодову базу не ускладнено, пробу заархівовано.

## 5. Результати на Nokia E90 та статус Nokia C5-00.2

1. **Nokia E90 (Gran Turismo 600f DSA):**
   - VRAM `ps1_vram8000.bin` варіантів Base та Candidate побайтово ідентичний (1 048 647 B, SHA256 `e2003300...`, фінальний цикл 394 683 195).
   - Швидкодія (4 прогони A/B/A/B): Base 34 573 / 34 115 ms (медіана 34 344 ms), Candidate 34 056 / 34 169 ms (медіана 34 112.5 ms, Δ -0.67%).
   - Оскільки другий прогін кандидата показав регресію +54 ms, а розкид лежить у межах 0.3%, результат швидкодії на E90 кваліфіковано як **невизначений (у межах апаратного шуму)**.
   - Оригінальний стан апарата повністю відновлено.
2. **Nokia C5-00.2:**
   - Виявлено порт `COM5` (SPP), демон активний (`IDLE`, пам'ять 180.7 MB).
   - Виконано лише операції зчитування (`INFO`, `STATUS`, `LS`, `STAT`, `GET` 20-байтного хешу).
   - Спроба `GET` великого бінарника зупинилася на 160 KB через відсутність клієнтського ReadTimeout у скрипті розгортання. Записів на апарат не виконувалося, стан вихідного віддаленого EXE лишається неперевіреним. Апаратні випробування швидкодії **не проводилися (NOT RUN / BLOCKED)**.

## 6. Межі вимірювань (Measured Limitations)

- Виміряний виграш -0.87% стосується виключно конкретної сцени Crash Bandicoot (кадри 4700→5300), де Gouraud-растеризація становить значну частку навантаження.
- Не робиться тверджень про загальний приріст FPS для всієї бібліотеки ігор PS1 або про доведений глобальний приріст на іграх з переважанням текстурованих спанів без Gouraud (наприклад, GT чи WipEout).
- Частоти N95 зафіксовано точковими знімками регістрів (330.24 / 165.12 МГц) до та після випробувань, а не безперервним моніторингом.
