Первинні джерела/пошук рідних FPS (2026-10-05):
GT 30: прямо у дорученні.
Crash 30: Andy Gavin, автор рушія, інтерв'ю Ars War Stories https://arstechnica.com/video/watch/war-stories-how-crash-bandicoot-hacked-the-playstation-to-run/ (йдеться про зберігання animation vertices 30fps).
WipEout 30: автор порту після читання коду PS1 https://phoboslab.org/log/2023/08/rewriting-wipeout (physics assumes30fps); Digital Foundry original frame test https://www.youtube.com/watch?v=FVk3Z7wK5AU .
Cast60: TAS record https://tasvideos.org/497G (1293frames/21.550sec at60) — VBlank, не достатній доказ visibleFPS. Нативний порт60 https://velxio.dev/blog/posts/castlevania-sotn-on-esp32-s3/ — не замір PS1; не видавати його за оригінальне залізо.
Для Colin,Colony,NFS,Rayman,RC,Trek,Warzone,Wing пошук зроблено, надійної числової частоти в первинних джерелах не встановлено. Відгуки про плавність/швидкість не задають FPS. Частоти емуляторів інших людей не є рідними FPS. PC/PSP/нові ремастери не PS1.
2026-10-05 continuation: Julian Gold, Colony Wars: Red Sun postmortem, Game Developer August 2000 pp54-55, https://media.gdcvault.com/GD_Mag_Archives/GDM_August_2000.pdf . Legacy code inherited from prior Colony Wars titles was fixed at two video frames (30 FPS NTSC, 25 FPS PAL); Red Sun changed it to frame-rate independent. This supports a 30 FPS inference for original Colony Wars; explicitly label inference, not a direct measurement of the original title. Castlevania 1997 developer interview https://shmuplations.com/symphony/ does not state native FPS; leave unknown pending a numerical primary source.
Wing navigation controls: original PSX manual pp.4/11, https://download.wcnews.com/files/manuals/Wing%20Commander%20III%20PSX%20-%20Manual.pdf ; Circle/Triangle cycle carrier action spots; Cross activates selected spot; Flight Control -> Attend Briefing -> wingman -> Fly Mission. No native FPS claim from this manual.
